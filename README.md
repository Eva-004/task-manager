# Task Manager

Task Manager is a simple task management application that helps users create, view, search, filter, edit, and delete tasks. Task data is stored in the browser's localStorage, so tasks remain available after refreshing the page.

Live Demo: https://task-manager-peach-five-38.vercel.app/

## Tech Stack

- Next.js
- React.js
- JavaScript
- Tailwind CSS
- DaisyUI
- HeroUI
- React Icons
- React Toastify
- localStorage

## Features

- Create new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Search tasks by title
- Filter tasks by status
- Task status and priority
- Due date
- Task statistics
- Empty state when no tasks are available
- Data persistence using localStorage

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Eva-004/task-manager

Go to the project directory:

cd task-manager

Install dependencies:

npm install

Run the development server:

npm run dev

Open the application in your browser:

http://localhost:3000

## Build for Production

npm run build
npm start
